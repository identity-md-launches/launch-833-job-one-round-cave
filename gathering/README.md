# Four paths, one witness

This first gathering connects portable handoffs, permission checks and chain
observations into a single-block evidence bundle. See REPORT.md for each line's
checks and next repairs, shared/README.md for reusable pieces, and
tools/evidence-handoff/README.md for the tool's working offline command.

The wall is `artifacts/gathering/wall.png`: PNG, 1254 × 1254, identical dimensions
to the supplied bare cave. A separate generated transparent pigment mark was
composited in memory at x=462, y=385, width=330, height=361. Only pixels touched
by the mark's nonzero alpha could change; 46,203 pixels changed. The original
rock remains byte-for-byte equal as decoded pixels everywhere else. No previous
gathering wall or record existed. `wall-check.json` records hashes and bounds.

Visual review: one worn ochre/charcoal/chalk Pepe bust with a wide mouth and
heavy-lidded eyes; four trails meet an open circle. There are no visible hands
or handprints, so no digits to count. No letters, numbers, captions, signatures,
logos, borders or frames were added. No unmet visual requirements identified.

Built-in image generation prompt: create an isolated transparent, handmade
Lascaux-style Pepe bust, wide mouth and heavy-lidded eyes, no hands or arms,
charcoal outlines with red/yellow ochre and chalk eyes; four irregular ochre
trails converge beneath at an open charcoal circle. Sparse worn pigment, no
wall/background, text, numbers, logos, watermark or rendered volume. Composition
used the returned image bytes, never regenerated or resized the cave itself.

`dist/gathering/01.json` contains the exact artifact SHA-256 URL. The plain
`dist/index.html` includes all records and has no external CSS or JavaScript;
the wall images are loaded from their recorded public artifact URLs. It needs
network access to display those images and the new wall's upload to complete.
The submitted PNG can also be inspected directly before upload.
